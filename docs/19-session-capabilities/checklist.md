# 会话审批与扩展能力 Checklist

> 每一项通过运行代码或观察行为来验证，聚焦系统行为。

## 会话一轮的能力

- [ ] 配置了 MCP、技能和 Hooks 的工作区里，会话一轮能用上它们。其中一项装不上时，这一轮仍开始，已装上的能力仍可用，并出现可读中文警告（验证：故意放坏一项配置后发送，观察事件流，对应 AC1）
- [ ] 这一轮结束后，该 MCP 连接不再保留（验证：结束后再发起依赖旧连接的调用，看到重新连接或明确的未连接，而不是复用上一轮，对应 AC1）
- [ ] 工作区没有这三项配置时，会话仍能用六个内置工具完成一轮。聊天页没有斜杠命令入口（验证：空配置发送一次，并查看页面，对应 AC2）

## 权限与询问

- [ ] 没有规则命中时，只读工具直接执行，不出现询问。写文件、改文件、执行命令和 MCP 工具会停下来，选择前不执行（验证：各触发一次，观察事件流里有没有 `approval`，对应 AC3）
- [ ] 危险命令或越出工作区的路径被直接拒绝，四个放行选择都不能让它执行（验证：提交放行后工具仍未执行，对应 AC4）
- [ ] 询问事件包含工具名、对象、参数摘要和四个选择。晚订阅仍能看到未完成的询问并提交。聊天页四个按钮是中文，提交后询问消失，后续输出继续增量出现（验证：先订阅再补订阅，并在页面上点一次，对应 AC5）
- [ ] 拒绝和仅本次放行只作用于这一次。拒绝后这一轮还能继续。本会话放行后，同一段对话的下一轮相同调用不再询问，另一段对话仍询问。重启服务或执行进程后，本会话放行失效（验证：连续两段对话各跑一轮，再重启，对应 AC6）
- [ ] 永久放行后，终端后续会话和 HTTP 会话对这次精确调用都不再询问。记录与终端在同一处，且只含这次的精确参数（验证：网页上永久放行后，用终端触发同一次调用，并查看规则内容，对应 AC7）
- [ ] 一直不回答，直到超时、取消或执行停止。该工具没有执行，结果按拒绝处理。对话不再忙，可以再发下一条（验证：取消一个正在询问的轮次后再发送，对应 AC8）
- [ ] 对已结束的询问，或不属于这一轮的选择，提交被拒绝并说明原因，原结果不变（验证：重复提交同一次选择，对应 AC9）

## 并发、访问与隔离

- [ ] 等待选择时，其他空闲对话仍能发送并排队。同一段对话再发新消息仍因正忙被拒绝（验证：两段对话同时观察状态码，对应 AC10）
- [ ] 开启与会话发送相同的访问限制后，不带凭证不能提交选择。健康检查仍可访问（验证：带与不带凭证各请求一次，对应 AC11）
- [ ] 审批展示和事件流里不出现配置密钥、MCP 环境变量的值或请求头的值（验证：用含密钥的配置触发一次询问，检查事件文本，对应 AC12）
- [ ] 一次性任务仍自动放行六个内置工具，事件流里没有询问，向它提交选择会被拒绝。原有提交、等待、查询、取消和事件流行为不变（验证：跑一次性任务并调用选择入口，对应 AC13）
- [ ] 聊天页在这一轮先结束时，表明该询问已按拒绝处理，不再停在四个选择上（验证：询问出现后取消这一轮，看页面，对应 AC14）

## 编译与测试

- [ ] `npm run typecheck` 通过（验证：命令退出码为 0）
- [ ] 在 `server` 目录执行 `python -m unittest tests.test_api`，全部通过（验证：命令退出码为 0）
- [ ] 终端的日常启动路径没有改成依赖会话一轮（验证：不带新参数的原有启动方式仍可进入）

## 端到端场景

- [ ] 场景 1：启动服务，打开聊天页，在会话里要求执行一个会改文件的命令。页面出现四个中文选择，且文件尚未改动。选择仅本次放行后，文件发生变化，后续正文继续出现（验证：浏览器里观察按钮、文件时间和事件流）
- [ ] 场景 2：同一询问出现后不点选择，取消这一轮。页面标明已拒绝，该对话可以再发一条。接着用一次性任务提交同一句要求，过程中没有询问（验证：浏览器与一次性任务接口各观察一次）
