# MewCode MCP 客户端 Spec

## 背景

MewCode 现在只能使用六个内置工具。外部能力要等接上 MCP 之后，才能在启动时发现并注册进来。权限闸门已经会在执行前判断放行、询问或拒绝，计划模式也只会把只读工具交给模型。这一章要把远端工具接进同一套工具中心，而不是另开一条调用路径。

## 目标

- 启动时读取用户级和项目级配置里的 Server 列表，连上之后发现工具并注册进现有工具中心
- 支持两种传输：本地子进程走标准输入输出，远程走 Streamable HTTP
- 按 JSON-RPC 2.0 收发。每个请求带编号，回包按编号配对，互不串线
- 一次连接按顺序完成三步：初始化握手、列出工具、之后按需调用工具
- 发现到的工具包成现有工具接口。模型只看到工具名、说明和参数，不知道它来自 MCP
- 注册名是「服务器名__工具原名」。和六个内置工具撞名时，跳过该工具并给出警告
- 这些工具都视为有副作用，执行时串行。计划模式不把它们交给模型
- 调用前仍走现有权限闸门。规则里的工具名用注册全名，模式对着这一次参数的 JSON。没有规则命中时，按当前档位处理
- 多个 Server 的连接在进程内缓存，退出时关闭。某一个握手失败、列出工具失败或调用失败，不影响其他 Server，也不阻止进入对话
- Server 列表按用户级打底、同名项目级覆盖来合并。供应商配置的读取方式不变
- 配置缺字段，或 `${VAR}` 在环境中不存在时，不连接该 Server，给出可读警告
- 这一章不做资源、提示词、采样，也不做健康检查和自动重连

## 功能需求

- F1: 启动时读取 Server 列表并尝试连接。每个 Server 独立进行，不等待其他 Server 成功。全部处理完后才进入对话。没有任何 Server，或列表为空时，仍只使用六个内置工具，程序正常启动
- F2: 每个 Server 在配置里声明传输种类。本地子进程一种，必须给出要执行的命令，参数和环境变量可选。远程一种，必须给出地址，请求头可选。环境变量和请求头的值里可以写 `${变量名}`，启动时用当前环境展开。命令、参数和地址按原文使用，不做展开
- F3: Server 列表来自现有的用户级配置和项目级配置，不另起文件。先取用户级，同名 Server 再被项目级整段覆盖，不做字段拼接。供应商配置仍按现在的方式读取，不因为这份合并而改变
- F4: 服务器名是这段映射的键。只允许字母、数字、下划线和单个连字符，并且不能包含连续两个下划线。不合法、缺传输种类或缺必填项时，跳过该 Server 并给出可读警告
- F5: `${变量名}` 在环境中不存在时，不连接该 Server，给出可读警告，不用空字符串代替。其他 Server 继续
- F6: 本地传输为每个 Server 启动一个子进程，用标准输入输出按行收发 JSON 消息。子进程的标准错误不参与配对。远程传输使用 Streamable HTTP：同一次请求的结果可以是一整份 JSON，也可以是一段流式事件，拼成同一次回包。连接在进程内保持，退出时关闭
- F7: 消息按 JSON-RPC 2.0。需要回包的请求带唯一编号，只把相同编号的成功或失败回包交给这次请求。没有编号的通知不等待回包。编号对不上的回包不拖垮进程
- F8: 连接建立后按顺序做两步，然后才注册工具：初始化握手、列出工具。握手只声明工具能力，不声明资源、提示词或采样。协议版本谈不拢、握手失败或列出工具失败时，不注册该 Server 的工具，其他 Server 不受影响。列出工具若有多页，取完再注册
- F9: 每个远端工具注册进现有工具中心。模型看到的名字是「服务器名__工具原名」，说明和参数结构沿用远端给出的内容。与六个内置工具同名时，跳过该工具并警告。六个内置工具的名字和行为不变
- F10: 这些工具都视为有副作用。和写文件、改文件、执行命令一样串行执行，不与其他工具并发。计划模式不把它们放进交给模型的工具列表。执行模式可以看到并调用
- F11: 真正执行前走现有权限闸门。规则中的工具名是注册全名。模式对着这一次参数的 JSON。键的书写顺序不同但内容相同，视为同一次参数。没有规则命中时，按当前档位决定拒绝、询问或放行。本会话放行和永久放行只记住这次的参数 JSON，不放宽到整个工具
- F12: 危险命令黑名单和路径沙箱不作用于这些远端工具。它们没有命令文本，也没有项目内路径。能否执行只由规则和档位决定
- F13: 模型调用后，把参数原样交给对应 Server，并把文本结果交回模型。远端声明这次调用失败，或传输中断、超时、子进程已退出时，这次调用成为结构化失败，说明原因。Agent Loop 不因此结束。不自动重连。该 Server 之后的调用继续失败，其他 Server 仍可调用
- F14: 单个 Server 在启动或调用中失败，不阻止进入对话，也不取消其他 Server 已注册的工具。警告在启动后的界面里能看到

## 非功能需求

- N1: 仍以现有终端程序交付。配上 Server 之后，能在常见桌面终端里启动并进入对话
- N2: 配置打不开、某一条不合法、某个 Server 握手失败或调用失败，都不得让进程崩溃。失败和警告用可读中文说明原因
- N3: 警告里可以出现变量名、服务器名和失败原因，不得把已经展开的环境变量或请求头内容打印出来
- N4: 每个 Server 的握手和列出工具要有上限等待时间。超时则跳过该 Server 并警告，不把进入对话无限期卡住。单次工具调用沿用现有的工具超时，超时后这次调用失败，循环继续
- N5: 同一个 Server 上若有多条尚未完成的请求，回包必须按编号回到对应的那一条，不能串到另一次调用
- N6: 子进程的标准错误可以忽略，但不能把协议消息拆乱，也不能因为标准错误里有内容就判定连接失败
- N7: 界面文案和新增注释使用中文
- N8: 本轮至少能在本地验证：一份会应答的本地 Server 能列出工具并完成一次调用；一个故意失败的 Server 不会挡住另一个成功的 Server；缺环境变量时该 Server 不连接

## 不做的事

- 不做 MCP 的资源、提示词和采样。握手时不声明这些能力，也不提供读取资源或拉取提示词的入口
- 不做 Server 健康检查，也不在断开后自动重连。连接在启动时建立，进程退出时关闭。中途断开后，该 Server 的后续调用直接失败
- 不把远端工具当成只读工具。计划模式不暴露它们，执行时一律串行
- 不把远端工具纳入危险命令黑名单或路径沙箱。能否执行只看权限规则和当前档位
- 不根据一次确认把某个远端工具放宽成全部参数都允许。本会话和永久放行只记这一次的参数 JSON
- 不改供应商配置的读取方式。两份配置只合并 Server 列表，同名时项目级整段覆盖
- 不在命令、参数和远程地址里展开 `${变量名}`。展开只发生在环境变量和请求头的值上
- 不提供单独的 Server 管理界面。增删改靠手改配置，重启后生效
- 不替换六个内置工具，也不改变 Agent Loop 的停止条件。远端调用失败只是一次工具失败
- 不做 OAuth 或其他登录流程。远程认证只使用配置里写好的请求头
- 不做图形界面

## 验收标准

- AC1: 没有 Server，或列表为空时可以启动。模型仍能看到原来的六个内置工具（对应 F1）
- AC2: 一个能正常握手的本地 Server，其工具以「服务器名__工具原名」出现，说明和参数结构与远端给出的一致。与某个内置工具同名的那个远端工具不出现，并有可读警告（对应 F8、F9）
- AC3: 用户级和项目级有同名 Server 时，实际使用的是项目级整段配置，不是两边字段拼在一起。供应商配置仍按原来的规则读取（对应 F3）
- AC4: 服务器名不合法、缺少命令或缺少地址时，跳过该 Server 并给出警告。同一次启动里其他合法 Server 仍能注册工具（对应 F4）
- AC5: 环境变量和请求头里的 `${变量名}` 会展开成当前环境的值。变量不存在时该 Server 不连接。警告里能看到变量名，看不到已经展开的密钥或请求头内容（对应 F2、F5、N3）
- AC6: 写在命令、参数或远程地址里的 `${变量名}` 保持原文，不会被替换（对应 F2）
- AC7: 本地子进程按行收发消息。标准错误里有内容时，仍然可以列出工具并完成调用（对应 F6、N6）
- AC8: 远程传输对同一次请求，既能收下整份 JSON，也能把一段流式事件拼成同一次结果（对应 F6）
- AC9: 同一个 Server 上两条尚未完成的请求，回包按编号各自返回，不会串线。没有编号的通知不会让调用方一直等待。编号对不上的回包不会让进程退出（对应 F7、N2、N5）
- AC10: 握手失败、协议版本谈不拢，或列出工具失败时，该 Server 没有工具被注册。另一个成功 Server 的工具仍然可用，程序仍能进入对话（对应 F8、F14、N1）
- AC11: 列出工具有多页时，后面几页的工具也会被注册（对应 F8）
- AC12: 计划模式下，模型看不到这些远端工具。执行模式下看得到，并且它们不会和其他有副作用的工具并发执行（对应 F10）
- AC13: 没有规则命中时，默认档会询问，严格档直接拒绝，放行档直接调用。精确规则只命中相同参数；参数键的顺序不同仍算命中。本会话或永久放行之后，换一组参数会重新判断（对应 F11）
- AC14: 放行档下，远端工具不会因为参数看起来像危险命令，或参数里带有项目外路径，就被黑名单或路径沙箱拒绝（对应 F12）
- AC15: 调用成功时，模型能看到文本结果。远端报错、调用超时或子进程已退出时，模型收到失败说明，当前循环不因此结束。之后对同一 Server 的调用仍然失败，不会自动重连。其他 Server 仍可调用（对应 F13、N4）
- AC16: 某个 Server 的握手超过等待上限时会被放弃，界面能看到中文警告，对话仍然可以开始（对应 F14、N2、N4、N7）
