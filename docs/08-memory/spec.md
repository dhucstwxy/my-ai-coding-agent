# 记忆与会话 Spec

## 背景

MewCode 目前每次新会话几乎「从零开始」：系统提示虽预留了自定义指令与记忆槽，但未加载任何项目/用户文件；会话落在全局整文件 JSON，与「当前项目」脱节。长任务可以靠上下文压缩续聊，但跨会话的偏好、纠正与项目知识无法沉淀，中断后再开往往要重复交代。

## 目标

- 启动即恢复：加载分层项目指令与记忆索引，让助手开局就带上规范与长期印象
- 工作记忆可靠：项目内 JSONL 会话可追加、可恢复、可清理；异常恢复行为可预期
- 长期记忆自动增长：在对话自然结束后异步整理四类笔记，用户级与项目级分开
- 与现有压缩能力协作：恢复时若上下文过大，先走既有压缩，再继续对话
- 明确边界：本步不做向量库、RAG、团队同步

## 功能需求

### 项目指令

- F1 三层加载：拼装系统提示时读取三份可选文件并拼接——项目根 AGENTS.md、项目 .mewcode/AGENTS.md、用户 ~/.mewcode/AGENTS.md；缺失则跳过。
- F2 优先级顺序：高优先级在前：项目根 > 项目 .mewcode > 用户级。
- F3 @include：指令正文支持引用其他 Markdown；最大嵌套 5 层；用已访问集合防止环路；解析后的路径不得逃出约定根（项目指令相对项目根，用户指令相对用户 .mewcode）；违规引用跳过并产生可读警告。
- F4 注入位置：展开后的指令文本进入系统提示的「自定义指令」槽；不写入会话存档正文。

### 会话存档（JSONL）

- F5 存储位置与格式：会话仅存放于当前工作区 .mewcode/sessions/；每会话一个 .jsonl 文件；按行追加消息记录。不再使用全局 ~/.mewcode/sessions 下的整文件 JSON（旧数据可抛弃）。
- F6 会话 ID：新建会话 ID 形如 YYYYMMDD-HHMMSS-xxxx（日期时间 + 短随机后缀），降低同秒冲突。
- F7 无独立 meta：列表所需的 ID、标题、消息数、更新时间等由扫描各 JSONL 得出，不另维护 meta 文件。
- F8 恢复健壮性：读档时坏行跳过；存在未配对的工具调用（有调用无对应结果）时从该处截断不完整尾部；若估算上下文超过窗口安全阈值，恢复后、继续对话前先跑既有压缩一次；若距上次活动超过 24 小时，在本次请求中插入一条时间跨度提醒（临时提醒，不落盘）。
- F9 过期清理：启动时删除超过 30 天未更新的会话文件及其附属工具结果目录（若有）。

### 自动记忆

- F10 四类笔记：自动笔记分为用户偏好、纠正反馈、项目知识、参考资料；以带 frontmatter 的 Markdown 单条文件存放。
- F11 分库存放：用户级笔记在 ~/.mewcode/memory/；项目级在项目 .mewcode/memory/；各自维护索引文件。
- F12 索引注入：处理用户请求、拼装提示之前加载记忆索引，注入系统提示的「记忆」槽；注入内容不超过 200 行且不超过 25KB，超出则截断（保留靠前内容）。
- F13 异步更新时机：仅当自主循环因「最终回复且无工具调用」自然完成时，在后台异步调用模型更新笔记与索引；去重与归类由该次模型调用判断。
- F14 更新失败静默：异步记忆更新失败不影响主对话，不向用户界面报错。

### 协同

- F15 工具结果落盘路径：过大工具结果写入项目 .mewcode/sessions/{会话ID}/tool-results/，与既有轻量压缩衔接。

## 非功能需求

- N1 追加可靠：正常追加写会话时，崩溃最多丢失最后不完整的一行；已成功写入的行应可读回。
- N2 列表可接受延迟：会话列表通过扫描项目内 JSONL 生成；在数十个会话量级下应在短时间内完成。
- N3 提示体积可控：记忆索引遵守 200 行 / 25KB；项目指令展开后总文本上限 100KB，超出截断并警告。
- N4 不阻塞主路径：自动记忆更新不得阻塞用户看到最终回复与输入下一轮。
- N5 兼容压缩：会话恢复后的超限处理复用既有上下文压缩，不另造第二套摘要策略。
- N6 路径安全：@include 与记忆/会话路径解析不得读出约定根之外的任意文件。

## 不做的事

- 不做向量数据库、嵌入检索或按查询召回记忆
- 不做团队/多机记忆同步与冲突合并
- 不做旧版全局整文件 JSON 会话的迁移或导入
- 不维护独立的会话 meta/索引数据库文件
- 不在本步做 Skill 激活或技能市场
- 不提供图形化记忆编辑界面（可用文本编辑器直接改文件）
- 不在取消、报错、达迭代上限等非「自然完成」路径上触发自动笔记
- 不实现除既有压缩以外的第二套会话摘要算法

## 验收标准

- AC1（F1/F2）：三层都存在不同内容的 AGENTS.md 时，自定义指令区按「根 → .mewcode → 用户」顺序包含三段；缺某层时其余仍加载。
- AC2（F3）：合法 @include 展开进正文；深度大于 5、环路、逃出根目录的引用被跳过，并有可读警告。
- AC3（F4）：指令内容出现在系统提示自定义指令槽，会话 JSONL 中无整份指令副本。
- AC4（F5/F6）：新建会话在项目 .mewcode/sessions/ 产生 YYYYMMDD-HHMMSS-xxxx.jsonl；全局旧 JSON 会话目录不再作为读写目标。
- AC5（F7）：会话列表能显示标题与大致消息规模，且项目下无单独会话 meta 文件依赖。
- AC6（F8）：JSONL 插入坏行后仍能打开会话；未配对工具尾部被截断；超大历史恢复会触发压缩；距上次活动超过 24 小时再继续时，请求中出现时间跨度提醒。
- AC7（F9）：超过 30 天未更新的会话文件（及附属工具结果目录）在启动清理后不再保留。
- AC8（F10/F11）：自然完成后，用户级或项目级 memory 目录出现带 frontmatter 的笔记或索引被更新；两目录隔离。
- AC9（F12）：请求前记忆索引进入系统提示记忆槽；索引超过 200 行或 25KB 时实际注入不超过上限。
- AC10（F13/F14）：仅「无工具调用完成」触发异步更新；更新失败时主对话正常结束且界面无记忆错误提示。
- AC11（F15）：轻量压缩落盘路径位于项目 .mewcode/sessions/{id}/tool-results/。
- AC12（N4）：最终回复展示后用户可立即输入下一轮，不必等待记忆更新结束。
