# 斜杠命令 Spec

## 背景

MewCode 已有若干斜杠行为（压缩、计划/执行、权限），但分散在对话门面里用临时解析拼起来，缺少统一注册、别名冲突检测、Tab 补全，也没有把「本地确定操作」与「交给 AI 的对话」在入口处清晰分流。清屏、查状态这类事若走模型，既慢又费 Token，行为还不稳定。

## 目标

- 建立命令注册与分发机制：斜杠输入优先走本地命令，未命中才进 AI
- 启动即校验别名冲突，冲突则立即失败退出，避免运行时才暴露
- 用界面控制抽象解耦命令与具体终端界面实现；状态栏显示 [DEFAULT]/[PLAN] 等短标记
- 支持别名与 Tab 补全（隐藏命令不参与补全）
- 内置十个高频命令，覆盖帮助、压缩、清屏、模式、会话/记忆/权限/状态查询与审查提示
- 明确不做：用户自定义命令、动态生成提示词、命令级权限（留给 Skill）

## 功能需求

### 注册与解析

- F1 注册中心：集中登记命令元数据——名称、别名、描述、用法、类型（本地 / 影响界面或会话状态 / 提示词）、可选参数提示、是否隐藏、处理入口。
- F2 启动冲突检测：启动注册阶段若主名或别名冲突，进程立即失败退出并给出可读原因。
- F3 解析规则：以 `/` 开头视为命令候选；第一个空格前为命令名、之后为参数字符串；命令名转小写（大小写不敏感）；空输入不进入分发。
- F4 未命中引导：能解析为命令形态但未注册时，给出未识别提示并引导使用 `/help`；不以该整行作为普通用户消息送给 AI。

### 分流与界面抽象

- F5 入口分流：用户回车时先走命令分发；命中则本地执行；非命令输入才交给 AI 对话循环。
- F6 界面控制端口：命令通过抽象能力操作界面与会话上下文（至少：显示本地消息、清空当前界面消息列表、将预设提示作为用户消息送入 AI、切换计划/执行模式、切换权限档、查询状态信息）；命令实现不依赖具体渲染框架。
- F7 状态栏标记：计划模式显示 `[PLAN]`，执行模式显示 `[DEFAULT]`；可并列权限短标（如 `STRICT` / `DEFAULT` / `ALLOW`）。

### 补全

- F8 Tab 补全：对以 `/` 开头的输入做补全；唯一匹配则直接补全命令名；多个匹配则展示候选菜单；标记为隐藏的命令不参与补全与默认 `/help` 主列表。

### 内置十命令

- F9 `/help`：本地；列出可见命令的名称、别名、简述与用法。
- F10 `/compact`：本地；触发既有手动压缩（可带备注）；不把命令原文当作用户任务写入；不开额外闲聊回合。
- F11 `/clear`：影响界面；仅清空当前界面消息显示，不修改会话存档文件。
- F12 `/plan`：影响会话状态；进入计划模式；可带任务正文——有正文则切换后把正文送入 AI，无正文则只切换并提示。
- F13 `/do`：影响会话状态；退回执行模式；可带任务正文，规则同 F12。
- F14 `/session`：本地；打印当前会话 ID、标题、消息数、存档路径。
- F15 `/memory`：本地；打印项目/用户记忆 INDEX 是否存在、路径、规模概况（行数/大小一类）。
- F16 `/permission`（别名 `/perm`）：影响会话状态；参数为 `strict|default|allow`；可带后续任务正文（切换后可选送入 AI）；无合法档位时提示用法。
- F17 `/status`：本地；一屏汇总：模式标记、权限档、当前会话短讯、最近 token/缓存概况（若有）、压缩熔断是否打开。
- F18 `/review`：提示词型；将固定「审查当前会话/近期工作并给出风险与建议」类提示作为用户消息送入 AI。

## 非功能需求

- N1 本地命令确定且省 Token：help/clear/session/memory/status 及纯切换类路径不调用模型。
- N2 启动失败要响：别名冲突时进程退出码非 0，错误信息含冲突的名称对。
- N3 补全可交互：Tab 补全在终端界面中可操作；多候选时展示列表（本步不强制方向键点选）。
- N4 兼容既有能力：`/compact`、`/plan`、`/do`、权限切换的核心语义与现网一致，仅迁入注册中心。
- N5 可测试：解析与注册冲突检测可不依赖真实终端即可验证。

## 不做的事

- 不支持用户自定义命令或从配置文件热加载命令
- 不做运行时动态拼装/生成提示词模板引擎（`/review` 使用固定文案即可）
- 不做命令级权限控制
- 不在本步实现 Skill 系统或插件式命令包
- 不做图形化命令面板；补全以终端 Tab + 候选列表为主
- 不把 `/clear` 做成删除会话存档或不可恢复清空历史文件

## 验收标准

- AC1（F1/F2）：故意注册两条同别名命令时，启动失败且错误信息点明冲突；正常启动十命令可查询。
- AC2（F3/F4）：`/HELP` 与 `/help` 等效；`/unknown` 不进 AI，并提示使用 `/help`；空回车无副作用。
- AC3（F5）：普通句子仍进 AI；`/status` 等本地命令不触发模型请求。
- AC4（F6/F7）：`/plan` 后状态栏出现 `[PLAN]`；`/do` 后为 `[DEFAULT]`；权限切换后短标更新。
- AC5（F8）：输入 `/c` 再 Tab：若仅 compact 匹配则补全；若多匹配则出现候选列表；隐藏命令不出现。
- AC6（F9）：`/help` 列出可见命令含用法。
- AC7（F10）：`/compact` 仍能触发手动压缩（可带备注）。
- AC8（F11）：`/clear` 后界面消息列表为空，但会话存档文件内容仍在。
- AC9（F12/F13）：`/plan` / `/do` 无参只切模式；有参则切模式并把正文送 AI。
- AC10（F14/F15/F17）：`/session`、`/memory`、`/status` 输出含约定字段且不调模型。
- AC11（F16）：`/permission strict` 与 `/perm allow` 均生效；非法参数提示用法。
- AC12（F18）：`/review` 后出现一轮 AI 对话，用户侧可见审查类提示已送出。
- AC13（N1）：对 `/help`/`/clear`/`/status` 打桩或观察，确认无模型调用。
